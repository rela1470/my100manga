# DLsite 成年コミック 調査記録（R18版の表紙・購入リンク源）

2026-10-15 に DMM アフィリエイトの審査が本家・R18版とも落ち（理由非公開）、DMM は断念した（`docs/dmm.md` は PoC の記録として残す）。
R18版（my100shunga）の表紙と購入リンクの代わりとして DLsite を実測した記録。**まだ Worker には組み込んでおらず、
アフィリエイトの申請もしていない**。

計測ツールは `scripts/dlsite-probe.mjs`（使い捨て）。

## 1. 規約（2026-10-15 に確認）

[アフィリエイトパートナー規約](https://www.dlsite.com/home/affiliate/regulations)（2024年12月10日改定、運営は株式会社エイシス）。

- DLsite 自体が成人向けを売っているので、アダルトサイトを禁じる条文は無い。
- 第5条: 登録の可否は当社の判断、拒否の理由は開示しない（DMM と同じ）。申請には DLsite のユーザー登録が要る。
- 第8条: 「内容が不明または乏しく、異様な外観を含む内容」のサイトは不可。**DMM で落ちた原因と疑っている点がそのまま当てはまる**ので、
  申請前に R18版の「アフィリエイトは一切掲載していない」の文言を外し、リストを溜めておく。
- 第8条2項: 主要なコンテンツの表示にログインが要るサイトは、ゲスト用パスワードの提供等が条件。年齢確認ゲートはログインではないので当たらない想定。
- 画像の利用（ホットリンク・保存）についての条文は規約にもガイドにも見当たらない。**未確認事項**（4節）。
- 報酬率は形式別（ガイド上は画像で、数値は本文から読めなかった。紹介記事ではマンガ 12.5%）。

## 2. 取り方（実測で分かったこと）

**公開の商品 API は無い**。公開の検索ページと作品ページ用の JSON を使う。

- 検索: `https://www.dlsite.com/books/fsr/=/language/jp/keyword/<語>/per_page/100/page/1/`（`books` = 成年コミックのフロア）
  - Cookie `adultchecked=1` を付ける。
  - **空白は `+` で区切る。`%20` だと 403** になる。
  - robots.txt は `/*/fsr/=/*/per_page/*/page/` を禁止し、`page/1/` だけ許可。**取れるのは 1 ページ目（最大 100 件）だけ**。
  - 結果の各項目に 作品 ID（`BJ…`。同人の `RJ…`・ゲームの `VJ…` も混ざる）、題名、著者、出版社（`alt="… [出版社]"`）、表紙 URL が載る。
- 作品情報: `https://www.dlsite.com/books/product/info/ajax?product_id=<ID>&cdn_cache_min=1` → JSON に価格、販売中か（`on_sale`）、
  **アフィリエイト不可フラグ `affiliate_deny`** がある。
- **ISBN はどこにも無い**（作品ページにも JSON にも無い）。題名・著者・出版社で照合するしかない。
- 表紙: `https://img.dlsite.jp/modpub/images2/work/books/<ID の千の位で切り上げたディレクトリ>/<ID>_img_main.jpg`。**317×450 前後・45〜165KB**。
  検索結果に URL がそのまま載るので組み立てる必要はない。
- 利用条件（`https://www.dlsite.com/llms.txt`）: **毎秒 2 リクエスト・毎分 120 リクエストまで**。失敗時は 30 秒空けて 2 回まで。400/401/403/404 は再試行しない。
  （robots.txt には `Crawl-delay: 10` もある。）

### 照合のやり方（スクリプトの実装）

1. MADB のシリーズ名（コロンの後の副題と、括弧の読みを外したもの）で検索する。
2. DLsite の題名が シリーズ名で**始まる**ものを候補にする。DLsite は副題や版の名前を足していることが多い
   （「絶頂多発地帯」→「絶頂多発地帯 イキ地獄へようこそ」、「義理ですからっ」→「義理ですからっ【デジタル特装版】」）。
3. 巻数: シリーズ名の後の最初の数字が巻数と一致すること（巻数なしなら、数字なしか 1）。
4. 著者が一致すること（著者の括弧書き〔`月下冴喜(若宮参太)`〕は外す）。MADB に著者が無ければ出版社の一致で代える。
5. 見つからなければ最初の著者名で検索し直して、同じ判定をする。

## 3. 実測結果（2026-10-15）

R18 dev の D1 から 成年向けの巻を読み取り専用の SELECT でランダムに 60 巻抜いた（DMM のときとは別の 60 巻）。

| 結果 | 件数 |
|---|---|
| **自動で確定（題名＋巻＋著者/出版社が一致）** | **35 / 60（58%）** |
| うち表紙あり（12KB 以上） | 35（全件） |
| うちアフィリエイト可（`affiliate_deny=0`） | 35（全件） |
| うち著者名で検索し直して見つかったもの | 3 |
| 題名だけ一致（自動では確定できない） | 5（目視では 3 件が正しく、2 件が別作品） |
| 見つからない | 20 |

- **目視で正しいものまで含めると 38 / 60（63%）**。DMM（FANZA）の同条件では電子版 38%・通販とどちらか 50% だったので、**DMM より多い**。
- 題名だけ一致した 5 件の内訳
  - 正しい: 「インモラルな放課後」（MADB の著者 吉野志穂 / DLsite 吉野志保、出版社もキリブックスの再刊）、「ティド計画美々」（おかわり / OKAWARI）、
    「インモラルーティーン」（DLsite 側の著者欄が空）。
  - 誤り: 「メイドさんといっしょ」→ 同人の音声作品（`RJ…`）、「淫乱天使」→「淫乱天使と恋する少年」（別作品）。
  - → 本番に入れるなら、ID が `BJ` で始まるものだけに絞る。題名だけの一致は自動適用せず、管理画面の候補に積む。
- 見つからない 20 件の傾向: 1990 年代の久保書店・フランス書院・二見書房の絶版本が多い。中には**改題されているもの**もある
  （「LOVE LOVE SWEET」は DLsite では「ラブラブ・スィート」）。これは題名では照合できない。
- **版の違い**: 【デジタル特装版】【完全版】【DLsite限定特装版】や、別の出版社からの再刊（キリブックス・松文館・大洋図書）として載っているものがある。
  紙の本とは表紙が違う可能性がある（DMM の電子版と同じ問題）。
