# DLsite 成年コミック 調査記録（R18版の表紙・購入リンク源）

2026-10-15 に DMM アフィリエイトの審査が本家・R18版とも落ち（理由非公開）、DMM は断念した（`docs/dmm.md` は PoC の記録として残す）。
R18版（my100shunga）の表紙と購入リンクの代わりとして DLsite を実測した記録。**アフィリエイトは 2026-10-15 に承認され、
2026-10-16 に Worker へ組み込んだ（`src/dlsite.ts`、未デプロイ。7 節）**。DMM は 2026-10-16 に再申請の問い合わせもゼロ回答で断念した。

計測ツールは `scripts/dlsite-probe.mjs`（使い捨て）。

## 1. 規約（2026-10-15 に確認）

[アフィリエイトパートナー規約](https://www.dlsite.com/home/affiliate/regulations)（2024年12月10日改定、運営は株式会社エイシス）。

- DLsite 自体が成人向けを売っているので、アダルトサイトを禁じる条文は無い。
- 第5条: 登録の可否は当社の判断、拒否の理由は開示しない（DMM と同じ）。申請には DLsite のユーザー登録が要る。
- 第8条: 「内容が不明または乏しく、異様な外観を含む内容」のサイトは不可。**DMM で落ちた原因と疑っている点がそのまま当てはまる**ので、
  申請前に R18版の「アフィリエイトは一切掲載していない」の文言を外し、リストを溜めておく。
- 第8条2項: 主要なコンテンツの表示にログインが要るサイトは、ゲスト用パスワードの提供等が条件。年齢確認ゲートはログインではないので当たらない想定。
- 画像の利用（ホットリンク・保存）は規約には無く、承認後にアフィリエイトのガイドで確認した（5節）。
- 報酬率は形式別（ガイド上は画像で、数値は本文から読めなかった。紹介記事ではマンガ 12.5%）。

## 2. 取り方（実測で分かったこと）

**公開の商品 API は無い**。公開の検索ページと作品ページ用の JSON を使う。

- 検索: `https://www.dlsite.com/books/fsr/=/language/jp/keyword/<語>/per_page/100/page/1/`（`books` = 成年コミックのフロア）
  - Cookie `adultchecked=1` を付ける。
  - **空白は `+` で区切る。`%20` だと 403** になる。
  - robots.txt は `/*/fsr/=/*/per_page/*/page/` を禁止し、`page/1/` だけ許可。**取れるのは 1 ページ目（最大 100 件）だけ**。
  - 結果の各項目に 作品 ID（`BJ…`。同人の `RJ…`・ゲームの `VJ…` も混ざる）、題名、著者、出版社（`alt="… [出版社]"`）、表紙 URL が載る。
- 作品情報: `https://www.dlsite.com/books/product/info/ajax?product_id=<ID>&cdn_cache_min=1` → JSON に価格、販売中か（`on_sale`）、
  **アフィリエイト不可フラグ `affiliate_deny`** がある。
- **ISBN はどこにも無い**（作品ページにも JSON にも無い）。題名・著者・出版社で照合するしかない。
- 表紙: `https://img.dlsite.jp/modpub/images2/work/books/<ID の千の位で切り上げたディレクトリ>/<ID>_img_main.jpg`。**317×450 前後・45〜165KB**。
  検索結果に URL がそのまま載るので組み立てる必要はない。
- 利用条件（`https://www.dlsite.com/llms.txt`）: **毎秒 2 リクエスト・毎分 120 リクエストまで**。失敗時は 30 秒空けて 2 回まで。400/401/403/404 は再試行しない。
  （robots.txt には `Crawl-delay: 10` もある。）

### 照合のやり方（スクリプトの実装）

1. MADB のシリーズ名（コロンの後の副題と、括弧の読みを外したもの）で検索する。
2. DLsite の題名が シリーズ名で**始まる**ものを候補にする。DLsite は副題や版の名前を足していることが多い
   （「絶頂多発地帯」→「絶頂多発地帯 イキ地獄へようこそ」、「義理ですからっ」→「義理ですからっ【デジタル特装版】」）。
3. 巻数: シリーズ名の後の最初の数字が巻数と一致すること（巻数なしなら、数字なしか 1）。
4. 著者が一致すること（著者の括弧書き〔`月下冴喜(若宮参太)`〕は外す）。MADB に著者が無ければ出版社の一致で代える。
5. 見つからなければ最初の著者名で検索し直して、同じ判定をする。

## 3. 実測結果（2026-10-15）

R18 dev の D1 から 成年向けの巻を読み取り専用の SELECT でランダムに 60 巻抜いた（DMM のときとは別の 60 巻）。

| 結果 | 件数 |
|---|---|
| **自動で確定（題名＋巻＋著者/出版社が一致）** | **35 / 60（58%）** |
| うち表紙あり（12KB 以上） | 35（全件） |
| うちアフィリエイト可（`affiliate_deny=0`） | 35（全件） |
| うち著者名で検索し直して見つかったもの | 3 |
| 題名だけ一致（自動では確定できない） | 5（目視では 3 件が正しく、2 件が別作品） |
| 見つからない | 20 |

- **目視で正しいものまで含めると 38 / 60（63%）**。DMM（FANZA）の同条件では電子版 38%・通販とどちらか 50% だったので、**DMM より多い**。
- 題名だけ一致した 5 件の内訳
  - 正しい: 「インモラルな放課後」（MADB の著者 吉野志穂 / DLsite 吉野志保、出版社もキリブックスの再刊）、「ティド計画美々」（おかわり / OKAWARI）、
    「インモラルーティーン」（DLsite 側の著者欄が空）。
  - 誤り: 「メイドさんといっしょ」→ 同人の音声作品（`RJ…`）、「淫乱天使」→「淫乱天使と恋する少年」（別作品）。
  - → 本番に入れるなら、ID が `BJ` で始まるものだけに絞る。題名だけの一致は自動適用せず、管理画面の候補に積む。
- 見つからない 20 件の傾向: 1990 年代の久保書店・フランス書院・二見書房の絶版本が多い。中には**改題されているもの**もある
  （「LOVE LOVE SWEET」は DLsite では「ラブラブ・スィート」）。これは題名では照合できない。
- **版の違い**: 【デジタル特装版】【完全版】【DLsite限定特装版】や、別の出版社からの再刊（キリブックス・松文館・大洋図書）として載っているものがある。
  紙の本とは表紙が違う可能性がある（DMM の電子版と同じ問題）。

## 4. 公式 API の有無（2026-10-15 にファクトチェック）

- 規約（2024-12-10 改定）にも改定の告知にも、API・データフィード・XML/CSV についての記述は無い。`llms.txt` もクローラ向けの上限を書いているだけ。
- 「承認済みのアフィリエイター向けに限定の提供がある」と書くブログ（sanagi-lab）と、「DLSite公式API連携」をうたう WordPress プラグイン（note）があるが、
  どちらも出典が無く裏付けが取れない。
- Rust の `dlsite`（[ozonezone/dlsite-rs](https://github.com/ozonezone/dlsite-rs)）・`dlsite-rs-next`（BK927、dlsite-gamebox のフォーク）は個人の非公式ライブラリで、
  検索ページの HTML と `product/info/ajax` を読むだけ。2節の取り方と同じで、API があることの根拠にはならない。
- → 公開 API は無い前提で組む。承認済みアフィリエイター向けの API があるかは、管理画面を見るかサポートに聞く。

## 5. 画像の利用条件・リンクの形（2026-10-15 にアフィリエイトのガイドで確認）

ガイドの原文の要点:

- 作品画像（紹介画像・サムネイル画像・ミニ画像・サンプル画像）の**改変は禁止**。拡大縮小は縦横比を保っていれば可。
- **商業コミックフロア（成年コミック・TL・BL のコミック/ドラマCD）の画像は、ダウンロードして利用することはできない**。
  紹介（表紙）画像・サムネイル画像・ミニ画像の**リンクのみ**利用できる。
- `img.dlsite.jp/resize/` の URL の画像は、予告なく変更・削除されることがある。
- アフィリエイトリンクのタグは、常識的な範囲（スタイル指定での装飾など）なら変えてよい。**a タグの href は変えない**。
- iframe を使ったアフィリエイトリンクには制限がある。使うならページの URL を添えて問い合わせる。
- アフィリエイトリンクを通して自分で買った分は報酬の対象外。
- 表示の文言を運営はチェックしないが、景表法などの法令に違反すると報酬の対象外になる。

リンクのドメインは `dlaf.jp`（`https://dlaf.jp/` は `https://www.dlsite.com/` へ 301）。リンクは管理画面のアフィタグ生成で作る。

### 組み込むときの制約

楽天・Yahoo の表紙とは別の経路にする。

- 表紙は `img.dlsite.jp/modpub/images2/...` に**直リンク**する（`resize/` は使わない）。
- `/cover` を通さない（Worker がダウンロードすることになる）。R2 にも保存しない。
- トリム（`src/covertrim.ts`・`public/cover-fit.js`）をかけない（改変になる）。表示は今の `object-fit: contain` のままでよい。
- X シェア画像（`src/shareImage.ts`）には合成しない（ダウンロード＋改変）。DLsite の表紙のところは書影なしの枠などで代える。

## 7. 組み込み（2026-10-16、未デプロイ）

- `src/site.ts` の `dlsite`（R18版だけ true）。`commerce: false` はそのまま（楽天・Yahoo 等は引き続き呼ばない）。
- 表紙: `src/covers.ts` `resolveCovers` の Tier 1–3（R18版では無効）の後ろに DLsite の段を足した。成年向けの巻（`volumes.is_adult = 1`）だけ
  `src/dlsite.ts` `dlsiteResolve` で引き、2 節の照合（`BJ` で始まる ID だけ）で確定したら img.dlsite.jp の URL を `covers` に入れる。
  書名だけ一致は `cover_suggestion`（suggest_count 0。管理画面の「自動」）に積む。全年齢の巻と DLsite に無い巻は「表紙なし」で確定。
- 速度: リミッタ DO の `"dlsite"` インスタンス（1.1 秒に 1 件）。検索ページと `product/info/ajax` は Cache API で 1 日持つので、
  同じシリーズの 2 巻目以降は作品情報の 1 件だけで済む。1 巻で最大 3 リクエスト（書名検索・著者名検索・作品情報）。
- 5 節の制約: `/cover` の許可ホストに img.dlsite.jp は無い（403）、`public/cover-fit.js` のトリム対象でもない。
  X シェア画像は `src/shareImage.ts` が DLsite の表紙を取得せず、出典にも載せない（その枠は表紙なし）。
- 購入リンク: `public/affiliate.js`。表紙が DLsite の巻だけ、表紙 URL の作品 ID から「DLsite（電子）」のリンクを作る。
  画像参考元も DLsite の作品ページへ。紹介 ID は secret `DLSITE_AFFILIATE_ID`（`window.__AFF__.dlsite`）。
  入っていれば PR 表記とフッターのアフィリエイト注記が出る。リンクの形は
  `https://dlaf.jp/books/dlaf/=/t/s/link/work/aid/<ID>/id/<作品ID>.html`（**管理画面のアフィタグ生成と要突き合わせ**）。
- R18版の利用規約第8条・about・privacy（外部送信に DLsite を追加）・books-guide を書き換えた（「アフィリエイト一切なし」を外した）。
- デプロイ時: secret `DLSITE_AFFILIATE_ID` を r18 / r18dev に入れる → デプロイ → **直後に** `db/r18-reset-adult-empty-covers.sql` を
  R18 の D1 に流す（今まで「表紙なし」で確定していた成年向けの巻を引き直すため）。
- 未確認: Workers の送信元 IP から DLsite の検索ページが 403 にならないか（手元の curl では 200）。403 は未確定扱いで
  キャッシュしないので、締め出されても誤った「表紙なし」は残らない。
