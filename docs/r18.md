# R18版の準備メモ

本家（全年齢）と同じコードを、別の Worker（別ドメイン・別 D1/R2/キュー）としてデプロイする方針。
違いは `wrangler.jsonc` の vars `SITE_VARIANT`（`"general"` / `"adult"`）で切り替える。

## 済んでいるもの（SITE_VARIANT で切り替わる）

| 対象 | 場所 | R18版での挙動 |
|---|---|---|
| サイト種別の定義 | `src/site.ts` | 名前・ハッシュタグ・成年向けの扱いをここに集約。未設定・不明な値は本家扱い |
| 成年向けの拒否 | `src/adult.ts` | `findAdultIsbns` / `hasAdultTitleMatch` が空を返す（検索・追加・公開で止めない） |
| MADB ライブ検索・補完 | `src/madbLive.ts` | SPARQL の成年向けフィルタを外す |
| 表紙ソースの ADULT 判定 | `src/rakuten.ts` `src/yahoo.ts` `src/ichiba.ts` | 書名・ジャンルの成年向け判定で弾かない |
| 静的 HTML の表記 | `src/analytics.ts` `applySiteIdentity` | 「My 100 Manga」とcanonical/og:url の本家ドメインを差し替え、`<html data-site>` を付ける |
| 閲覧ページ・404・エラー画面・フッター | `src/index.ts` `src/footer.ts` `src/util.ts` | サイト名を `site(env).name` から出す |
| 配色 | `public/styles.css` `:root[data-site="adult"]` | ピンク系（仮）。トークンの差し替えだけで済む |
| SNS シェア文言・ハッシュタグ | `public/share-x.js` | `window.__SITE__` から読む |
| エッジキャッシュ | `src/edgeCache.ts` | キーに種別を含める（同じゾーンに置いても混ざらない） |

## 残り（決めること・作ること）

- **名前・ドメイン・ハッシュタグ**: `src/site.ts` の `adult` は仮の値。
- **収録データ**: 取り込み（`scripts/ingest.mjs`）は成年向けを本体の表から外し、`adult_volumes` に最小限の列だけ残している。R18版用に「成年向けも取り込む」オプションが要る。R18版は成年向けだけを扱うのか、全年齢も含めるのかを先に決める（成年向けだけなら逆向きの拒否が要る）。
- **年齢確認**: 初回訪問の 18 歳確認（同意を Cookie/localStorage に保存）、規約への記載。
- **広告・アフィリエイト**: AdSense は成人向けコンテンツ不可なので R18版の `ADSENSE_CLIENT` は空にする。Amazon アソシエイトも成人向けに制限あり。DMM/FANZA アフィリエイトは承認待ち。
- **静的ページの中身**: 利用規約・プライバシー・about・運営者・追加できる本は本文が本家前提。R18版の本文を別に用意するか、種別で差し替える仕組みを作る。`og-default.png`・favicon も。
- **robots.txt / sitemap.xml**: 本家ドメイン直書き。`applySiteIdentity` は HTML だけに効くので別途。
- **共有画像**: `src/shareImage.ts` の見出し「My 100 Manga」とブルーの配色（`COLOR`）は固定のまま。
- **インフラ**: `wrangler.jsonc` に R18 用の env を足す（D1・R2・キュー・Analytics Engine・Durable Object・ratelimit の namespace_id・routes はどれも非継承なので全部書く）。Cloudflare Access アプリ、Google OAuth のリダイレクト URI、Turnstile のホスト名、楽天 API の Referer も R18 ドメインで。
- localStorage のキー（`my100manga_*`）はオリジンが別なら衝突しないので変えなくてよい。
